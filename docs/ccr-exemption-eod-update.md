# CCR Exemption — End-of-Day Update

- Added **Request Exemption** flow on Approved CCRs when linked documents aren't all approved.
- Author picks which document(s) to exempt and adds optional notes.
- All company admins get an in-app notification; clicking it opens the Review dialog directly.
- Admin sees the documents + notes, records a decision reason, and clicks **Approve** or **Reject**.
- Approval unlocks **Mark Implemented**; requester is notified.
- Per-document scope — non-exempted docs still lock the gate.
- Full audit trail captured automatically.
- One additive DB migration applied. Ready to demo.
